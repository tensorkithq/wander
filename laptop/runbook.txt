PURPOSE
-------
This node is the controller / robot-IO. It:
  1. Holds the WebRTC LocalSTA connection to the Unitree Go2 Air (must be on the
     dog's network -- the cloud brain CANNOT reach the dog directly).
  2. Runs the low-latency REFLEX / safety layer (stop / avoid) -- stays local, on
     the laptop, NOT across the internet.
  3. Renders generative audio out the laptop SPEAKER (the dog's "voice"). Synth
     params come from the brain over DDS; this node makes the sound.
  4. Serves the Rerun browser viewer (the porthole) and the FastAPI/WebSocket the
     Expo companion app talks to.
  5. Joins the project tailnet and exchanges sensor/behavior messages with the
     GPU brain via CycloneDDS.

It does NOT run heavy perception or the LLM mood-agent -- those run on the GPU
brain node (see ../gpu/runbook.txt).

HARD RULES (do not violate)
---------------------------
1. LIGHT INSTALL ONLY. Do NOT install the 'base', 'perception', 'cuda', or 'all'
   extras -- they pull PyTorch + vision models (multi-GB) and will blow the ~38 GB
   disk. Perception lives on the GPU brain. This node installs only:
   unitree, web, visualization, dds (+ a light audio lib). See Stage 2.
2. KEEP INTERNET WHILE TALKING TO THE DOG. The Go2 must be reachable AND Tailscale
   must reach the cloud. Solution: put the Go2 onto YOUR LAN/router (STA mode), so
   the laptop stays on normal WiFi (internet + Tailscale) and reaches the dog by IP.
   Do NOT connect the laptop onto the dog's own AP -- that kills your internet
   (single WiFi radio) and the brain link dies. (Ethernet/USB-LAN is an alt.)
3. REFLEX LAYER STAYS LOCAL. Never route the tight stop/avoid loop through the
   cloud brain. Cloud = cognition/mood (latency-tolerant) only.
4. Use the uv-managed Python 3.12 venv for everything.

STAGE 1 — prerequisites
------------------------------------------------------------------------------
  # Homebrew (if absent): https://brew.sh
  # macOS system libs DimOS uses (from its install.sh macOS path):
  brew install portaudio libjpeg-turbo git-lfs gnu-sed

  source "$HOME/.local/bin/env" 2>/dev/null || export PATH="$HOME/.local/bin:$PATH"

STAGE 2 — light DimOS install (NO perception)
------------------------------------------------------------------------------
  mkdir -p ~/srv/reality-instrument && cd ~/srv/reality-instrument
  git clone https://github.com/dimensionalOS/dimos.git 2>/dev/null || (cd dimos && git pull)
  cd dimos

  # 3.12 venv (system python is 3.14 -> unsupported)
  uv venv --python 3.12
  source .venv/bin/activate

  # cherry-pick ONLY the light extras. NOT base/perception/cuda/all.
  uv pip install -e '.[unitree,web,visualization,dds]'
  uv pip install sounddevice numpy        # light generative-audio rendering

  VERIFY (watch the disk -- `df -h /System/Volumes/Data` should NOT approach 0):
    python -c "import dimos; print('dimos import ok')"
    python -c "import sounddevice; print('audio ok')"
  NOTE: if any extra tries to pull torch/CUDA, you picked a heavy extra -- back it
  out. This node must stay torch-free.
